# ✨ EmojiCraft Studio — Telegram Mini App & Bot

> **Полноценная студия для создания кастомных анимированных эмодзи, нарезки эмодзи-пазлов и инспекции ID в Telegram.**

Проект разработан для демонстрации в портфолио современного стека разработки под экосистему Telegram: **React 19 + TypeScript + HTML5 Canvas Motion Engine + Telegram WebApp SDK + Node.js (GrammY)**.

---

## 🌟 Ключевые возможности

### 1. 🎨 Emoji & Monogram Studio (Кастомные и анимированные эмодзи)
* **Процедурный векторный рендеринг:**
  * Базовые формы: *Смайлик с глазами вверх (как в популярных трендах), Крутой смайл в очках, 3D Глянцевое Сердце, Огонь, Алмаз, Звезда, Щит, Корона*.
  * Кастомная буква или символ по центру / на лбу с поддержкой drag & drop перемещения пальцем по холсту.
  * 3D-эффекты: шариковый глянец (Balloon reflection), неоновая аура, стикерный контур.
* **Анимационный движок (60 FPS):**
  * ✨ **Sparkle & Shine:** лучистый блик в виде 4-конечной звезды со шлейфом искр скользит по контуру буквы.
  * 💧 **Liquid Drip:** реалистичные капли краски/чернил плавно стекают с буквы вниз.
  * 💓 **Neon Pulse:** мягкое дыхание масштаба и пульсирующее свечение.
  * 🪂 **Float & Wobble:** физическое покачивание и упругий отскок.
* **Экспорт по стандартам Telegram:**
  * **Animated WebM (VP9 с альфа-каналом):** нативная запись Canvas через `MediaRecorder` для анимированных видео-эмодзи и стикеров Telegram!
  * **Static PNG (100×100):** строгий формат Telegram Custom Emoji.
  * **Sticker PNG (512×512):** формат обычных стикеров.

### 2. 🔤 Batch Alphabet Generator (Генератор полного алфавита в 1 клик)
* Возможность в один клик сгенерировать комплект из всех букв алфавита (Русский А-Я, Английский A-Z, Цифры 0-9) в выбранном стиле оформления.
* Упаковка и скачивание готового набора в **ZIP-архив** для быстрой загрузки в Telegram через BotFather/Stickers.

### 3. 🧩 Grid Slicer (Эмодзи-пазлы как в @EmojersBot)
* Загрузка любого изображения или постера.
* Выбор сетки нарезки: **2×2, 3×3, 3×4, 4×2**.
* Автоматическая нарезка на бесшовные плитки 100×100 px.
* Скачивание всего набора в ZIP и подсказка правильного порядка отправки в чат.

### 4. 🔍 Emoji ID Inspector (Детектор ID как в @PremiumEmojidBot)
* Определение скрытых системных `custom_emoji_id` из сообщений с кастомными эмодзи.
* Генерация готового кода для ботов:
  * HTML: `<tg-emoji emoji-id="...">⭐</tg-emoji>`
  * Markdown: `[⭐](tg://emoji?id=...)`
* Поиск исходных стикерпаков в Telegram.

### 5. 💬 Live Chat Simulator (Интерактивный симулятор Telegram)
* Отображение созданного эмодзи в реальном масштабе:
  * В статусе профиля (рядом с никнеймом пользователя);
  * Внутри обычного текстового сообщения;
  * Крупным стикером / реакцией.
* Переключение светлой и тёмной темы Telegram.

## 🛠 Технологический стек

### Frontend (Telegram Mini App):
* **React 19 / TypeScript / Vite** — высокая скорость сборки и типобезопасность.
* **Tailwind CSS v4** — современная стилизация и полная синхронизация с цветовой схемой Telegram (`themeParams`).
* **HTML5 Canvas 2D Context** — процедурная отрисовка градиентов, бликов, частиц и анимационных циклов без внешних тяжелых библиотек.
* **MediaRecorder API (VP9/WebM)** — аппаратный захват кадров с прозрачным фоном для Telegram Animated Stickers/Emojis.
* **JSZip** — клиентская генерация архивов для пакетного скачивания.
* **Lucide React & Canvas-Confetti** — иконки и микроинтеракции.

### Backend (Telegram Bot):
* **Node.js (ESM)**
* **GrammY** — современный высокопроизводительный фреймворк для Telegram Bot API.
* Парсинг сущностей `MessageEntity.custom_emoji` и взаимодействие со стикерным API.

## 🚀 Быстрый запуск

### 1. Запуск Mini App (Фронтенд):
```bash
cd client
npm install
npm run dev
```
Приложение откроется на `http://localhost:5173`.

### 2. Сборка продакшн-бандла:
```bash
cd client
npm run build
```

### 3. Запуск Telegram Бота (Бэкенд):
1. Перейдите в папку `server`:
   ```bash
   cd server
   npm install
   ```
2. Создайте файл `.env` на основе `.env.example`:
   ```env
   BOT_TOKEN=ваш_токен_из_BotFather
   WEBAPP_URL=https://ваш-домен-или-ngrok-url
   ```
3. Запустите бота:
   ```bash
   npm start
   ```
